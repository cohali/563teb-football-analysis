## 可以直接看到哪些分析结果？

已发布比赛可按三个玩法展示分析方向。阅读时应同时核对比赛、玩法和对应盘口；不同比赛采用的方向和可用资料会有差异。

- 胜平负：主胜、平局或客胜等分析方向。
- 亚洲让球：推荐支持哪一方，以及对应让球盘口。
- 大小球：偏向大球还是小球，以及对应进球数盘口。
- 推荐筛选：可查看重点推荐和吐血推荐等站内已标记分组；吐血推荐仅用于符合条件的主胜或客胜方向。
- 页面显示的概率和推荐标记属于对应分析与玩法，用来阅读模型判断，不能理解成比赛必然发生的结果。

## 完整报告不只给一个结论

先看结论，再了解支撑和需要留意的因素。根据该场比赛实际可用资料，完整报告可包括：

- 两队近期赛果、主客场表现和状态对比。
- 进攻与防守统计、过往交锋记录。
- 伤停、出场存疑信息，以及可用的首发阵容和阵型。
- 开赛天气、两场开球之间的时间间隔等比赛条件。
- 已采集的赔率、不同公司报价及赔率变化走势。
- 最终总结：本节点采用哪些方向，还有哪些不确定因素需要留意。

请同时查看报告时间和各项数据说明。资料缺失不等于已确认没有影响；赔率图展示的是实际采集到的记录，不代表连续实时行情。

## 赛后可以核对推荐结果

战绩看板提供近7天统计，可以按玩法、日期和联赛查看，并通过近7天战报逐场复盘。关注的不只是一个总命中率，还包括具体推荐与实际结果是否对应。

- 核对当时发布的方向、盘口和比赛结果。
- 分别查看胜平负、亚洲让球和大小球表现。
- 结合已结算有效样本数和日期范围阅读命中率。
- 区分全部推荐与重点、吐血等站内分组的统计口径。

比赛结算后统计会变化。历史结果不保证未来表现，应结合样本和逐场记录理解，不能只看单个百分比。

## 第一次使用，建议这样看

1. 打开官网，选择自己熟悉的联赛或球队。
2. 在预测页先看比赛卡片上的分析方向，再按时间、联赛或推荐分组筛选；也可以收藏关注的比赛。
3. 展开完整报告，核对分析时间、对应玩法和盘口，再看球队、阵容、赔率等背景。
4. 比赛结束后打开战绩看板和逐场战报，对照原先的分析结论与实际结果。
