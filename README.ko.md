# 563TEB · 축구 예측, 분석 결과와 경기 후 리뷰

**563TEB의 분석이 어떤 결론을 내렸는지, 어떤 방향을 선택했는지 확인하고 실제 경기 결과와 비교해 보세요.**

563TEB는 모델이 생성한 축구 분석을 제공하는 웹사이트입니다. 경기 카드의 선택 내용을 먼저 확인하고, 전체 보고서에서 근거와 상황을 살펴본 뒤 경기 후 성적 화면으로 결과를 검토할 수 있습니다. 현재 사이트는 영어와 중국어를 지원합니다.

## 어떤 분석 결과를 볼 수 있나요?

- 승무패(1X2): 홈 승리, 무승부 또는 원정 승리 방향.
- 아시안 핸디캡: 선택한 팀과 해당 핸디캡 라인.
- 총득점: 오버 또는 언더 방향과 기준 득점 라인.
- 주요 추천 그룹과 표시되는 경우 모델 확률.

제공되는 선택은 경기마다 다릅니다. 확률이나 표시는 경기 결과를 보장하지 않습니다.

## 전체 보고서에는 무엇이 있나요?

데이터 제공 여부에 따라 최근 흐름과 경기 결과, 홈·원정 성적, 공격·수비 통계, 상대 전적, 부상과 출전 상황, 선발 명단을 볼 수 있습니다. 경기 조건, 기록된 배당률, 업체별 비교, 채택한 방향과 주의할 사항의 요약도 포함될 수 있습니다.

보고서 시각과 데이터 설명을 확인하세요. 배당률 이력은 실제 수집된 관측 기록이며 끊김 없는 실시간 시세를 의미하지 않습니다.

## 경기 후 성적 확인

성적 대시보드는 최근 7일을 시장, 날짜, 리그별로 보여 줍니다. 경기별 리뷰에서는 공개된 선택과 라인을 해당 결과와 비교할 수 있습니다.

- 승무패, 핸디캡, 총득점을 구분해서 확인합니다.
- 적중률과 함께 판정된 표본 수 및 기간을 읽습니다.
- 전체 추천과 주요 추천 그룹의 통계를 구분합니다.

경기 결과 판정에 따라 통계가 바뀝니다. 과거 성적은 미래 결과를 보장하지 않습니다.

## 처음 사용하는 방법

1. 평소 관심 있는 팀이나 리그를 선택합니다.
2. 경기 카드의 분석 방향을 읽고 시간, 리그, 추천 그룹으로 필터링합니다. 관심 경기는 즐겨찾기에 저장할 수 있습니다.
3. 전체 보고서를 열어 시각, 시장, 라인과 배경을 확인합니다.
4. 경기 후 대시보드와 개별 리뷰에서 공개된 분석과 실제 결과를 비교합니다.
